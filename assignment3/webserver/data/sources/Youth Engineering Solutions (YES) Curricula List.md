# Youth Engineering Solutions (YES) Curricula Directory

This directory provides a structured list of curricula, engineering design units, computer science modules, and hands-on event activities created by Youth Engineering Solutions (YES) at the Museum of Science, Boston.

## 1. Preschool / Early Childhood

**Wee Engineer Units:** Introductory engineering challenges for young learners using everyday materials.

- Loud Noisemakers

- Wind-Powered Fans

- Wrecking Balls

- Rafts
