# Steps  

1. Complete one or more **tutorials** each on HTML5, CSS3, and responsive web design/media queries. Here are some options:  
   1. Textbook Chapters  
   2.  [w3schools.com](http://www.w3schools.com/)  
   3. [codecademy.com](https://www.codecademy.com/)  
   4. [lynda.com](http://www.lynda.com/) (free access using your Simmons ID and password)  
   5. other tutorial websites  
2. Individually, build the **main page of the website** that you’re building for ‘Assignment 4 Final Website’ using HTML5, CSS3, responsive web design, JavaScript and image manipulation. This should be informed by the information architecture and wireframes that were built for ‘Assignment 2 Information Architecture, Wireframe, & Mood Board’.   
3. Create a **subpage** that is linked from the web page. This can be about yourself, or any other topic or content that you think is appropriate.  
4. Demonstrate use of the following **coding techniques** through the main page, sub page, or both:  
   1. **Semantic elements:** HTML5 elements such as header, footer, aside, article, section, nav, bold, italics, etc.  
   2. One **external CSS file** to style both pages  
   3. ***Some styling*** e.g. colors, text, links, images, blocks of content, including positioning.  
   4. At least two **columns**  
   5. **Responsive** coding: meta viewport inside the head tag of your HTML, CSS3 media queries  
   6. At least one instance of **image** manipulation. Use **colors and images** that are appropriate to the content. Make sure all images are sized appropriately for the page. This means not just changing the size via the width element of the CSS, but resizing the original image.   
   7. At least one instance of **JavaScript** using an **external JavaScript file**  
5. **Validate** your code and fix any errors.  
   1. HTML: W3C Markup Validation Service ([http\://validator.w3.org](http://validator.w3.org)). You can also use [http\://infohound.net/tidy](http://infohound.net/tidy) to help tidy your page automatically  
   2. CSS: [http\://jigsaw.w3.org/css-validator](http://jigsaw.w3.org/css-validator)  
6. Check your site using different **browsers** and types of **devices.** The instructor will be testing on Chrome or Firefox browsers.  
7. **Upload** the pages to your Simmons web space by following the instructions in “upload your files to the Simmons Web Server” (see Lab 3, Part 3 under Week 3 in Moodle). Make sure you upload the HTML, CSS, JavaScript and image files within folders as appropriate.
