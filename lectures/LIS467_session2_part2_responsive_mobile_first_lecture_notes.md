## 2. The Canvas Analogy — Why Responsive Design?

💡 **The old days (print):** an artist painted on a **fixed-size canvas** or sheet of paper. Design was easy because you knew exactly the size of the surface you were working on.

⚠️ **The web today:** the "canvas" *changes*. The screen you design on at home may differ from:

- Another user's laptop screen size
- A large desktop monitor
- A **mobile phone** or **tablet**

🔑 The core challenge of responsive design: **How do you ensure your website looks good in different browsers and at different screen sizes?** Your canvas changes with every device.

⭐ **Ethan Marcotte** coined the term **responsive design**. His argument: the fixed-canvas control designers knew from the **print medium** was simply a function of the *limitations of the printed page*. The web doesn't have those constraints — so we should **embrace flexibility and design for it**.

## 4. Desktop-First vs. Mobile-First

| Approach | Process | Consequence |
|----------|---------|-------------|
| **Desktop-first (traditional)** | Design on/for a computer screen first, then try to cut content down to fit mobile | You start with maximum space and must trim afterward |
| **Mobile-first** | ⭐ Design for the small mobile screen first, then scale up to tablet, then desktop | Very little space **forces you to decide what is truly necessary** |

### Why mobile-first is advocated

- ✅ With minimal space, you must **focus on the key content** first
- ✅ Keeps the design aligned with the **goals of the website**
- ✅ Improves **usability** from the end user's point of view

### Direction of design

| Strategy | Order |
|----------|-------|
| Responsive (desktop-first) | Laptop/desktop → tablet → mobile |
| Mobile-first | Mobile → tablet → desktop |

## 5. Key Terms Glossary

| Term | Definition |
|------|------------|
| **Responsive design** | Designing a website so it adapts and looks good across different browsers, devices, and screen sizes |
| **Ethan Marcotte** | Web designer who coined the term "responsive design"; argued the web should embrace flexibility rather than mimic print's fixed page |
| **Mobile-first** | Design strategy starting with the smallest screen, forcing prioritization of key content, then scaling up |
| **Desktop-first** | Traditional strategy: design for large screens first, then reduce for smaller devices |
| **Fixed canvas** | The print-era assumption of a known, unchanging design surface — no longer true on the web |
| **CSS templates/frameworks** | Ready-made responsive solutions that simplify building adaptable layouts |
